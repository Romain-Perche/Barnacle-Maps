# Barnacle Maps

A minimal navigation web app: see the map, see where you are, search for a place and get the shortest walking route.

- Map: [Leaflet](https://leafletjs.com) + OpenStreetMap tiles
- Geolocation: browser Geolocation API
- Search: OSM Nominatim
- Walking route: OSRM foot profile (routing.openstreetmap.de)

## Run

    npm start      # serves on http://localhost:8080 (geolocation works on localhost)

## Test

    npm test
